# 評価記録（品質 / コスト / レイテンシ / 一貫性）

PLAN.md §7.8 の評価ハーネス。モデル・プロンプト・プロバイダを変更するたびに、
固定のサンプルコーパス（`samples/`）で回帰させ、結果をここに追記する。

## ルーブリック（採点軸 1-5）

| 軸 | 観点 |
|---|---|
| 分割の自然さ | 場面転換・視点変化・時間経過で適切に区切れているか |
| キャラ一貫性 | 同一キャラの顔・服・画風がコマ間でブレないか |
| 画風一致 | 指定した画風プリセットに沿っているか |
| プロンプト品質 | シーン記述が画像生成に十分な被写体/構図/光を含むか |

## コスト / レイテンシ予算（実測で更新）

| 工程 | レイテンシ目標 | 単価メモ |
|---|---|---|
| シーン分割(LLM) | 数秒 | 入出力トークン（プロンプトキャッシュで削減） |
| 画像生成 1 枚 | 5〜30s（先読みで隠蔽） | プロバイダ確定後に単価を記入 |
| TTFM（投入→最初のコマ） | ≤ 30s | 北極星指標（§11.1） |
